# RoutePulse CI — Frontend

Application React (Create React App + [craco](https://craco.js.org/), UI shadcn/Tailwind). Voir le [README racine](../README.md) pour la vue d'ensemble du projet.

## Scripts

- `yarn start` — serveur de dev sur [http://localhost:3000](http://localhost:3000), rechargement à chaud.
- `yarn test` — lance les tests (Jest + React Testing Library).
- `yarn build` — build de production dans `build/`.
